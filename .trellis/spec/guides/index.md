# 共享设计指引

按问题选择阅读，不要求每次任务把全部文档加载一遍。

- [复用与可维护性](code-reuse-thinking-guide.md)：新增模块、发现重复逻辑、重构边界时。
- [跨层检查](cross-layer-thinking-guide.md)：接口、持久化、权限或两个前端的行为联动时。
- [跨端契约](../contracts.md)：请求、结果与恢复语义的具体约束。
- [验证规范](../verification.md)：需要什么证据、哪些测试不必重复。

审查意见必须追到实际输入来源、调用路径和可观察后果。不要按评论数量、文件行数或机械覆盖率判断质量；不要把现存代码自动当成规范，也不要把规范建议冒充已经实现。
