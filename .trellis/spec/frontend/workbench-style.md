# 工作台视觉规范

工作台剧情首页按用户 2026-11-05 最新要求，采用游戏端 G2 的背景地图与透明浮窗；管理页保留 W-C。用户明确“首页”是进入战役后的剧情页，要求正常比例优先，且不显示折叠箭头。本文同步候选的实际令牌与组件；实现验证和待验收状态见 实现反馈，不据此视为 Claude Code 已验收或已部署。

唯一样式实现为 [app.css](../../../client-workbench/styles/app.css)。工作台面向 PC 主持、内容准备与长文编辑，行为、权限、草稿和异步生命周期以 [workbench.md](workbench.md) 为准。

## 主题与令牌

- 保留一套 `color-scheme:dark`，无主题开关。管理页用底色和留白组织；剧情页使用带单层 BG3 边框的玻璃浮窗，内部不嵌套带框卡片、不铺双层内框。
- 标签、表单和辅助说明使用本地 `DiceRealmSans`；页面/章节标题、人物名、剧情叙事及记录阅读正文使用 `DiceRealmSerif`。剧情装饰复用游戏端资源，不引入外部字体、CDN 或前端框架。
- 根字号 16px；`data-ui-scale` 125/150 对应 20/24px。文字用 rem/em，不能缩小正文来挤列。
- 颜色只在 `:root` 定义，规则引用 `var(--…)`；不使用 inline style 或脚本绕过 CSP。地图绘制的既有边界不变。

2026-11-05 重算 32 组文字/常用底色：最低 4.62:1（`text-muted` 对 `raised-strong`）；输入线对页面、面板、编辑底色为 3.94/3.57/3.30:1。装饰线不冒充控件边界。证据在 `.local/claude-codex-v3/theme-report.json`，后续改色须按实际组合重算。

剧情首页另用根令牌 `scene-glass`（`rgba(16,13,11,.74)`）、`scene-chrome`（`rgba(11,10,9,.62)`）、`scene-note`（`rgba(14,11,9,.28)`）与静态暗角；局部金色为 `#c9a66b` / `#f1d9a6`，辅助文字为 `#c0b29a`。上述 32 组旧纯色对比不是新玻璃背景的验证。当前页在实际地图及无图背景检查阅读效果；`backdrop-filter` 只模糊窗后背景，不模糊文字。BG3 原图与酒馆背景位于 `client-workbench/assets/game/`，由服务端嵌入资源清单托管；权限地图仍走原鉴权图片接口。

## 控件

- 管理页面板圆角 14px、控件圆角 8px；面板无描边与重投影。同类记录用细分隔、留白或浅一档底色，不再套带框卡片。剧情浮窗按 G2 复用 Tooltip 边框、DividerRight 装饰、普通铜色与主要青色按钮及其状态图，不用纯色矩形代替这些素材。
- `.btn` 为铜金文字与淡金底，`.btn-ghost` 透明；主按钮铜金渐变与深色文字，危险按钮朱红淡底与浅红文字。禁用保持可读及原有原因说明，同屏主操作通常一个。
- 页签用衬线字与当前项发光笔触；分类筛选用行内字、小菱形与当前笔触。装饰菱形用空内容的伪元素绘制，不进入按钮的可访问名称。
- 折叠入口不显示三角、箭头或 `summary` 原生 marker；保留标题文字、原键盘语义与真实内容，不用另一套箭头替代。
- 状态用彩点与明确文字，不使用带框胶囊，不能只靠颜色表达。
- 单行输入与下拉采用下划线，多行输入采用无框浅底编辑块。标签保持可见，placeholder 不代替标签。焦点环仍为 2px、外偏移 3px。
- 精细指针沿用紧凑控件，粗指针保留 44px 命中区；不为手机另建导航或操作方式。
- 说明只保留影响决策的信息，避免重复按钮名称和实现原理。规则中文名由 `rule-labels.js` 投影，载荷 ID 不变。
- 原生模态保留 top layer、inert、Esc、具名关闭、标题栏拖动、焦点恢复与独立滚动。处理栏不能替代真正需要确认的模态。

## 外壳与导航

左侧为横排文字窄栏，`--rail-w:4.75rem`，100% 时为 76px，随文字大小扩展。房间组为剧情、世界记录、邀请玩家、存档；系统组为剧本、地图图册、提示词，以及管理员的请求日志、AI 设置。当前项用淡金底和左侧亮条，分组名常显。权限继续由 `navigation.js` 过滤，无可见项的组不渲染；管理员未进入战役时仍可访问账户级页面。

导航内容可独立滚动。完整顶栏横跨页面，左侧为“主持手札”、战役名与身份/章节，右侧保留连接状态、阅读设置、唯一的全局刷新及账户圆标；长名称省略并保留 title，不挤掉操作。

100% 时主内容从 x=84px 开始，顶栏内边距 28px；常规页面最大宽 1800px、左对齐，AI 设置收敛到 1400px，单栏提示词阅读区不超过 90rem。页头统一用 `pageHead`，主操作在右侧，无侧栏的登录页居中。不新增手机布局。

## 剧情地图与浮窗

- 真实地图铺满背景，SVG 标记与图片使用相同的居中裁切；完整图、图外单位和隐藏单位图例由顶部“查看完整地图”打开，仍只读。没有地图时使用游戏端酒馆背景，不填演示地图。地图和浮窗复用一份 `dm/overview` 及已有图片缓存，不加轮询或接口。
- 左上地点/章节铭牌、左侧队伍与主持事项、右侧剧情及本轮执行过程组成浮窗，中间留出地图空间。队伍保留头像生命环、姓名/职业/AC、右对齐 HP、真实资源和状态。具体尺寸属当前候选实现，不能当作用户已验收。
- `.story-feed` 仍是唯一主阅读滚动。shell 为 `100dvh`，浮窗按实际余高分配；队伍和整个主持事项窗各自滚动，不给待办卡再设百分比高度截断其操作，不产生页面第二滚动条。
- 主持概览可收起并记住本机偏好；收起隐藏队伍和场景信息，保留背景地图和真实待办。普通席位不读取私密概览。失去权限、切换战役/时间线、销毁视图时，同时清理浮窗、背景标记及图片引用，并拒绝迟到响应。
- 打开审核/裁定事项时，处理窗位于地图区域，队伍和右侧剧情保持可见；关闭恢复场景内容与原收起选择。无待办、无概览时不留空主持窗，轮询不能自动打开处理窗。
- 处理栏保留独立滚动、关闭/返回、失败重试与原请求恢复。真实确认、角色资料及请求原文仍复用原模态。
- DM 叙事为无框正文，1.125rem 宋体、行高 1.95；玩家行动用左侧细线与紧凑署名，私密片段用虚线边界，对白仍用暖色。正文只生成文本节点，不解释 HTML。
- 检定保留同字号的名称、DC、总值与真实成功/失败；无 DC、多 DC 不合并成单一胜负，骰面细节放 title。转述图标保留 title、aria-label、键盘焦点及原权限。
- 执行过程保留图标、中文摘要和已保存步骤的详情；模型调用弱化为细分隔行，工具步骤突出。查询用 info，检定用暖色，写入用 success，拒绝用 danger，同时配文字/图标。未发生的写入或检定不得显示成功。

## 管理页面与草稿

- 世界记录保留原分类查询、分页和权限；左侧选记录，右侧显示完整摘要与原来源/纠错入口。不能把近期快照数当全量数，不添加设计稿中缺少真实依据的关系、出场次数等数据。
- 地图图册为目录/详情，选图才下载鉴权图片。用途、比例尺、两点校准、发布与当前图选择沿原接口和冻结版本；空图不显示尺寸控件，原始尺寸在图片容器内滚动。
- 剧本和存档使用原目录/详情；首次设定、剧本库、下载、恢复与破坏性操作流程不变。重开仍在页底危险区域。邀请玩家为房间/队伍与共享密码两栏，不新增建卡或审批流程。
- 全局请求日志为列表/详情；原卡片在剧情或提示词中复用时仍打开原详情窗。切选择先撤下旧正文，按请求 ID、战役和 run 核对详情；迟到、失败、销毁后不能覆盖当前内容。原始 JSON 仍需明确点击，不展示预测请求。
- AI 设置左侧选服务，右侧编辑。切换保留原控件与未保存值，仍由一次保存提交主、辅、图片配置；切目录不保存、不测试，密钥不回显，保存栏保持可达。
- 提示词仍是同一段落/全文/方法草稿与一次保存链。操作条、版本状态固定，目录与编辑区按剩余高度独立滚动，战斗提示词遵守同一规则。默认战斗提示词、导入、生效原文、注入位置与真实请求入口均保留。按钮在余宽不足时自然换行，不以非常用缩放牺牲正常比例的正文布局。

## 动效与验证

新内容淡入上移、侧栏入场与数值高亮沿 `presentation-motion.js` 的约 0.2–0.3 秒演出，点击/按键可结束。历史和重连内容不重播，`prefers-reduced-motion` 与已有本机开关关闭演出；不新增依赖、开关或计时器，不移动正文布局或抢阅读位置。

使用实际源码构建的嵌入工作台，优先在正常 100%、1920×1080 下逐项对照原稿，并检查常见桌面窗口下的页面、处理栏及长内容。保留已有阅读放大能力，不再把 150% 截图矩阵作为本轮视觉工作的主线。等待字体，核对 document 无横向溢出、剧情/提示词无外层第二滚动、底部操作可达、选择与草稿保留。`npm --prefix client-workbench test` 不代替实机截图；磁盘源码变化不代表旧运行包已更新。结果写入协作文件，未经 V1–V3 全部验收不更新日常包。
