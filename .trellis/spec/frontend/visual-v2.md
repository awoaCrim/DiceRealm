## 通用

- **不沿用旧组件外观**（用户原话：“既然我让你重构前端，说明原本的风格我大多是不满意的”）。只保留功能和字段。尤其禁止一排带细边框的小方块筛选/标签按钮。
- **设计稿不是功能清单**。稿中标为建议的项（工作台“近 7 天请求”图、世界记录“关联/出场”）未经单独确认不实现。演示数据和占位头像不进游戏。
- **高保真还原流程**（用户2026-11-04规定）。任务是高保真还原视觉稿，不是按视觉稿重新设计一个功能相似的界面。
  1. 实现前先分析视觉稿，列出布局结构、字体、颜色、尺寸、装饰素材和效果。
  2. 美术资源制作与组件开发分开。不能用纯色矩形代替复杂的装饰面板。
  3. 优先复用已有素材和 Prefab，不得无理由降级视觉。
  4. 每完成一个主要区域，都实际运行 Unity 并截图，与设计稿在相同分辨率下对比。重点看位置、大小、间距、颜色、字体、背景、边框和光效。
  5. 代码能运行不等于 UI 完成。拿不到实机截图时，必须说明“尚未完成视觉验收”。
  6. 先做视觉还原，再接交互和数据。缺数据不是省略视觉元素的理由：组件按设计稿做全，QA 截图用稿中样例填满（样例只在 QA 脚本里）。生产环境缺数据的项用已有素材回退或隐藏，并在交付时列出。
  7. 交付必须附 Unity 实际截图，以及与原稿仍存在的差异。
- **动效沿用现有规则**：`UiMotion` / U1 / U2 的动效规则不变。只展示服务器已定的结果，可跳过，减少动画时关闭，不重播历史。

## 游戏端（Unity）

### 实现技术（用户2026-11-04选定方案B）

- 游戏端界面逐页迁到 **UI Toolkit**（UXML + USS，Unity 6.3 运行时）。原因是现在的 uGUI 靠手写坐标，设计稿很难对齐。USS 的弹性布局、九宫格（Sprite 自带 border / `-unity-slice-*`）和过渡能直接翻译设计稿的 CSS。
- 迁移按页面进行，新旧共存。某一页迁完后，它的 uGUI 实现在同一单里删除，不保留两套。没迁的页面暂时继续用 uGUI。
- UXML/USS 放在 `Resources/UI/Toolkit/`。PanelSettings 在运行时创建，不手写 YAML。字体继续用项目里的思源字体；BG3 Sprite 直接作为 `background-image`。
- UI Toolkit 的 `filter: blur()` 只模糊元素自身，不能模糊背后的画面。毛玻璃仍由 uGUI 的 `UiBackdrop` 负责：它画在 UI Toolkit 面板上层，能模糊下面的画面（试点已验证，见下）。
- 迁移顺序：基础设施与主页试点 → 其余独立页面（房间、设置、建卡、角色、日志、检定）→ 最后主冒险。

试点（主页，2026-11-04）在QA Player里实测确定的做法：

- **宿主**：
  - `ToolkitHost.Create` 返回自己持有的根元素，由 `ToolkitAttach` 在每次启用时挂回UIDocument。UIDocument只在GameObject启用时才有根元素，测试里的App是未激活的。
  - 宿主销毁时一并销毁运行时PanelSettings。不销毁的话，残留的面板会影响后续测试。
  - 屏幕类（如 `HomeScreen`）只负责构建、显隐和激活。动作和可用状态仍由原来的所有者决定。
- **层级**：UI Toolkit画在uGUI下面。
  - 迁移后的页面显示时，上层任何不透明的全屏uGUI都要关掉，例如HUD的 `Backdrop`。
  - uGUI的GrabPass毛玻璃（`Veil`/`UiBackdrop`）能正确模糊下面的UI Toolkit画面，不需要另做模糊。
- **字体**：用 `-unity-font-definition`。`-unity-font` 会被默认主题覆盖，结果全是黑体。
- **字间距**：Unity 6.3对我们的字体按“百分之一em”渲染。USS里写设计稿的em值×100，例如 `.2em` 写 `20px`。
- **焦点**：UI Toolkit的焦点不是EventSystem选择。页面关闭后，屏幕类自己把焦点还给打开它的元素。
- **输入**：真实鼠标点击要经过Input System UI模块进入面板，`DesktopInputTests` 里有相应用例。
- **行为规则**：unity.md里的行为规则继续有效，例如设置全屏底层不透明。
- **禁用 USS `filter`**（房间页实测）：它的内置着色器不进Player构建，每帧报空着色器异常，整个面板都画不出来。背景压暗用 `-unity-background-image-tint-color`。
- **选择器优先级**：页面专用的外边距等要写成 `.unity-button.<类>`，否则会被 `.unity-button.dr-button--small` 这类组合选择器覆盖。ScrollView 内容区用后代选择器 `.<列表> .unity-scroll-view__content-container`。
- **验收工具**（`.local/ui-hifi/`）：
  - `measure.cjs`：用浏览器量出设计稿每个元素的位置、字体和效果。
  - QA 捕获脚本：导出 Unity 元素的位置和大小。
  - `review.cjs`：逐元素对比，偏差超过 4px 记为不合格，并输出叠加图和差异热图。
  - 用 `sips` 裁出同一区域，在 1:1 下对照。
- **线性色彩空间补偿**：项目用 Linear 色彩空间，Unity 在线性空间混合 UI 透明度，浏览器在 sRGB 空间混合，Unity 6.3 的 PanelSettings 也没有强制 Gamma 的选项。因此半透明效果在美术阶段预先补偿：
  - 暗色遮罩：a' = 1 − (1 − a)^2.2。
  - 暗底上的亮色光效：保留原 alpha，求解颜色 c' = sRGB(lin b + (lin(a·c + (1−a)·b) − lin b) / a)，b 是该效果所在的背景色。改 alpha 的做法不可行，8 位精度不够，会出现色带。
  - 光效必须按颜色烘焙，不能事后再染色。
- **美术管线**：
  - `AgentScripts/BakeUiArtV2.cs` 输出到 `Resources/UI/Art/V2`：CSS 滤镜背景、渐变、投影/发光、状态点、余烬、盾形头像框、标题光效。
  - `scripts/render-ui-text-effects.cjs` 用 Chromium 渲染设计稿 CSS 的 `text-shadow`，只取覆盖率；颜色和补偿由烘焙脚本用浮点计算，浏览器画布会把淡色量化掉。
  - 运行时不再生成贴图。
- **文字盒**：
  - 默认主题给 Label 加了内边距，统一清零。
  - CSS 的字间距在最后一个字后面也有，Unity 没有。带字间距的文字要补同样大小的右内边距（包括居中的按钮文字），否则后面的元素会左移。
  - USS 没有行高，多行正文用富文本 `<line-height>`。
- **叠加效果的层级**：`drop-shadow` 会连同元素自己的 `box-shadow` 一起发光，所以发光层要放在黑色投影层下面，单独一层，不能替换投影。
- **设置页（覆盖 HUD 的全屏页）**：放在自己的面板上（`ToolkitHost.OverlayOrder`），排在 uGUI 之上，不受界面辅助放大影响。
- **默认主题的状态底色**：下拉框在悬停、焦点、按下或展开时，默认主题会给输入区铺灰底，而且它的选择器带伪类，优先级更高；要用带同样伪类的选择器清掉。BG3 的 `DropdownHover` 是灰色高光，不能直接当悬停底图。
- **延迟提交的输入框按 Esc**：UI Toolkit 会把输入还原成旧值。如果需求是保留已输入的值，要在 TrickleDown 阶段先提交，再停止传播。
- **富文本行高的首尾**：`<line-height>` 只拉开行与行之间的距离。CSS 会在首行上方、末行下方各加半个行距，这部分用上下内边距补上。
- **栅格留余量**：固定宽度的列刚好放满时，缩放到 1280×720 会因舍入换行，右侧要留几像素余量。
- **建卡等全屏页**：放在 `ToolkitHost.PageOrder`（9）面板上，排在 uGUI HUD 之上、设置页（`OverlayOrder` 10）之下。
- **带子元素的 Button 不按自身文字定宽**：有图标或多段文字时，文字放在子 Label 里。按钮文字默认继承居中，行和卡片按钮要写左对齐。
- **ScrollView 只要纵向时**写 `mode="Vertical" horizontal-scroller-visibility="Hidden"`，否则会出现横向滚动条。
- **重绘后的焦点**：列表重建时记住当前焦点元素的名字，等到同名且可用的新元素出现后再还给它。
- **会变长的提示文字放进固定高度的区域**（例如属性页的提示），不能让它撑开表单，把下面的控件挤走。
- **空格宽度**：Unity 画的空格比浏览器窄约 3.5px（14px 字号）。含空格的按钮和状态文字用 `word-spacing` 补上。
- **仍用 uGUI 的页面也按设计稿还原**：角色窗口经用户选择，暂留 uGUI，等主冒险界面迁移时一起迁走。
  - 主冒险 HUD 也在 uGUI 上按 `game-2-saga.html` 重排（见 unity.md）。Tooltip 22px 取 0.77，Slot 10px 取 0.59。
  - 字间距用 `UiLetterSpacing`，只用于单行文字。
  - 九宫格边宽 = border ÷ (PPU × `pixelsPerUnitMultiplier`) × 100 个页面单位。Slot 8px 取 0.74，Tooltip 16px 取 1.058，12px 取 1.41。
  - 事实表由界面层画在空行上，`Body` 等文本出口保留完整原文。
- **以设计稿 CSS 为准**（用户2026-11-04选定“方案A：继续UI Toolkit，逐条翻译设计稿CSS”）。实现前读 `g2.css`、`bg3.css` 和页面内样式，按其中的数值翻译。本文件的映射表只是索引；两者冲突时，以设计稿为准并修正本表。
- **九宫格缩放按 Sprite 分别计算**：UI Toolkit 画出的边宽 = Sprite border × 100 / PPU × `-unity-slice-scale`。BG3 各 Sprite 的 PPU 不同（Button 40、Tooltip/ButtonPlain 150、Summary/Slot 200），所以 scale = 设计稿边宽 ÷ (border × 100 / PPU)，不能共用一个值。现有取值写在 `Visual.uss` 的注释里。
- **USS 没有的效果都是美术资源**（见上面的“美术管线”）：
  - 投影：高斯矩形，由两个方向的 erfc 相乘得到，九宫格 80。放在无框外层里，作为边框元素之前的 `.dr-shadow` 兄弟元素。
  - 发光：同一形状缩放 0.4。

### 毛玻璃

叙事浮窗、HUD 面板和大窗背景用**自写 GrabPass 模糊着色器**（项目为内置渲染管线，用户已选定，不引入 UIEffect、Translucent Image 等第三方包）。`UiMotion.Reduced` 开启时退回半透明纯色，不另加开关。

实现（V1）：`Resources/UI/Shaders/UiBackdropBlur.shader`（具名 GrabPass，5×5 高斯）+ `UiBackdrop`。窗口玻璃上覆盖 66% 底色，退回时 95%；Tooltip 只画边框（`fillCenter=false`），因为它的中心是不透明黑。`UiKit.Surface` 默认 Summary，`HudPanel` 用 Tooltip，全屏遮罩用 `Veil`。

### 外观

剧情首页使用 G2 毛玻璃、BG3 Tooltip 边框、标题装饰和按钮；内部信息分组保持单层，不再套第二圈边框。下面的 W-C 纯色面板及无框按钮规则适用于管理页。

- **单层扁平**：栏是圆角 14px 的纯色面板。面板之间只靠间距和底色区分，不画边框。
- **禁止嵌套框**（用户 2026-11-04 明确不喜欢）：
  - 面板内不再套带边框的卡片，不画双层内框。
  - 面板内分组只用浅一档底色 `--leaf-2`、圆角 10px，或用分隔线。
- **筛选**：一行文字，用小菱形分隔，数量写成上标。当前项金色，下方有一道发光笔触。
- **页内页签**：较大的宋体文字，当前项下方有发光线。
- **按钮**：
  - 次要按钮：金色字配淡金底，无边框。
  - 主按钮：纯金底、深色字，无内刻线。

- **状态**：彩色圆点 + 彩色文字，无框。
- **输入**：单行用下划线式；多行用 `--leaf-2` 底色块。
- 剧情首页按用户新要求复用现有 BG3 位图；其本机自用与发布边界仍遵循上文资源约束。
