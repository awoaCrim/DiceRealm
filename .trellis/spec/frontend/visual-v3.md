# 前端视觉规范 V3「墨卷」

2026-11-07 用户要求重写游戏端与工作台前端（不参考 V1/V2），选定 A「墨卷」方向，并在多轮反馈后确认 A3 版。本文件对已迁移页面**取代** [visual-v2.md](visual-v2.md)（G2 + BG3、W-C）与 unity.md / workbench-style.md 中的旧配色和布局；尚未迁移的页面在迁移前仍按 v2 运行。工作台已整体迁移：外壳、登录与剧情页按 A3 稿实现，其余页面统一使用本文件令牌与通用组件。

参考稿：原为 `artifacts/ui-design-iteration/v3/a3-ink/` 下的可交互稿（主冒险 `play.html`、工作台 `workbench.html`）。2026-11-21 该目录已丢失，用户确认无法找回；此后以本文件文字为准，游戏端视觉由用户看实机截图后调整。

## 1. 可实现性（游戏端必须遵守）

- 2026-11-21 起游戏端改为浏览器网页 `/play/`（见 [前端规范](index.md)），逐步替代 Unity；Unity UI Toolkit 版在网页对等前继续运行，不再新增界面。
- 视觉只用纯色与 alpha、细线边框、圆角（0 / 2px / 50%）；不用阴影、毛玻璃、滤镜或装饰性渐变（叙事流顶部的渐隐遮罩除外）。
- 动效短而可跳过：任意键或点击结束演出，系统“减少动态效果”时不播放。
- 字体只有思源黑体/宋体 CN Regular，只用 400 字重；层级靠字号、颜色、字间距、衬线与无衬线区分。

## 3. 游戏主冒险布局

画布基准 1920×1080，三块区域的位置在探索和战斗中都不变：

- **左栏（约 248）**：书名与状态 → 队伍（战斗时同一位置换成先攻名单，含本人生命/AC，敌人只显示伤势）→ 目标（当前任务与已知线索数，只读，悬停看线索，点击开冒险日志）→ 底部入口：冒险日志 J / 角色 C / 设置 Esc。取消顶栏。
- **中栏（1920 下约 760，窄窗口不少于约 580）叙事是主体**：章首（场景名 + 天气 + 状态签 + 一句处境）→ 叙事流 → 输入区。输入区从上到下：待处理提示条（等待投掷 / 轮到你行动 / 等待他人），战斗时的行动按钮与本回合预算，输入框加发送印。
- **右侧地图出血（约占窗口宽的四成，1920 下约 806×1080）**：用户 2026-11-21 试玩后认为原来约 736 的地图区偏小，窗口变窄时由中栏和地图一起让出宽度。没有外框，左缘用双墨线和中栏分开。探索时 1:1 显示并对准队伍所在地点（实现取舍：图片缩到 80% 以上就能完整放下时整图显示，不切掉一条边），压一层很淡的纸色；战斗时推近约 1.25 倍，在同一张地图上叠加方格。滚轮缩放、拖动平移，不常驻缩放工具；M 键展开大图。画外的已知地点在地图边缘给出指示。

投掷卡只覆盖并压暗地图区域，叙事保持完整可读。

## 4. 叙事流（可读性硬规则）

用户多轮反馈确认，按小说/剧本体排：

- 所有段落同一字号（宋体 20/36）、同一条左边线，不使用左侧说话人栏。
- 对话比旁白重要：写成「着色人名：正文」，正文用 ink，不加「」；旁白用 narration 色。区分靠墨色深浅，不靠字号。
- NPC 台词从旁白中拆成独立的对话行（需要叙事输出带说话人分段；没有分段时退化为把「」内文字加深）。
- 仅本人可见的内容是一段正文：段首小标签「仅你可见」，文字用 private 色，不做底色块或边框。
- 检定、动作回显、战报用黑体 15，一行连读，例如「⬡ 米洛　调查 DC 12 · d20 11 + 4 = 15 [成功]」。结果小方印紧跟在后面，不甩到行尾；悬停查看加值拆解。
- 时间放右侧，同一分钟只显示一次，悬停可见。
- 关键词只在第一次出现时用暖墨加淡下划线标出，之后与正文同色，悬停仍可点。

## 5. 交互

- 新的主持旁白逐字显现，标点处停顿；全文高度先预留；点击或按空格立即显示全文；新消息淡入。正文末尾显示“主持正在构思…”和队友的“正在输入 / 正在行动…”。
- 悬停卡：检定 → 加值拆解；队伍或先攻条目 → 角色卡；地图图钉、关键词 → 资料卡；不可用的按钮 → 不可用的原因。
- 投掷：需要本人投掷时自动打开一次；只有点「投掷」、按空格或输入“投掷”才掷骰；约 1 秒演出，可跳过；总值递增，印章落下；关闭不等于取消，可从提示条继续。
- 战斗：
  - 悬停格子显示移动消耗，点击移动并扣除预算。
  - 「攻击」进入选目标状态：圈出够得着的敌人，够不着的说明原因，Esc 取消。
  - 动作用完后，相关按钮置灰并说明原因。
  - 结束回合后先攻依次轮转，每个行动都有叙事节奏。
  - 自然语言输入与按钮等价。
- 检定成功等世界变化要在地图上同步反馈，例如路线浮现、地点标“新线索”、目标线索数更新。

## 6. 工作台剧情页

- 三栏：导航 | 剧情 | 右侧停靠栏。右栏在“主持概览”和“事项处理窗”之间切换，处理窗停靠显示、不是模态，剧情不被遮挡。
- 主持事项是剧情顶部的一条紧凑停靠条，每条事项一行，正在处理的那条有朱砂选中态；没有待办时整条不出现。
- 剧情消息与游戏端同一套规则（宋体 18/33）；“仅 赫拉 可见”同样是段首标签加赭色正文。“本轮步骤”仅主持可见，挂在对应 DM 消息下，成功轮默认折叠。
- 1920 与 1440 宽都要验证；窗口宽度小于 1680 时收窄导航和右栏。
