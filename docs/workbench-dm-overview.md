# 工作台主持概览

用户2026-11-03要求在剧情页常驻展示队伍、当前场景DM信息和DM地图；2026-11-05进一步要求剧情首页采用游戏端的背景地图与透明浮窗。实现归属 `dm-sidebar.js` / `DmOverviewService.cs`；W1功能已在日常包，本次 V3 视觉候选尚未更新日常包，状态见[当前进度](current-status.md)。

## 读取接口

`GET /api/v1/campaigns/{id}/dm/overview`，使用现有 `Authorization: Bearer …`。只有当前战役主持可读；普通玩家返回403。读取不改变游戏版本、存档或回执，不调用模型、掷骰或生成图片。它不加入AI工具目录、玩家快照或Unity DTO。

| 字段 | 含义与来源 |
|---|---|
| `campaignId` / `timelineId` / `version` | 当前战役、时间线和版本，用于拒绝旧进度响应 |
| `party` | 已有 `PartyMemberView[]`：未撤销且有角色的成员，沿用角色/头像投影；无角色主持不制造空角色 |
| `scene.id/title/summary` | 当前场景的既有基础资料 |
| `scene.npcs` | 当前实际场景的剧本NPC投影，主持可见尚未公开者；保留既有位置条件与会面状态 |
| `scene.records` | 当前场景的完整世界记忆记录，包含host私密和hidden记录；不采用AI情境的截断/筛选窗口 |
| `scene.authoredEncounter` | 当前场景剧本定义的遭遇，可能为null |
| `encounter` | 既有 `EncounterRead` 的DM投影，含当前遭遇、名册、布局和隐藏/发现信息 |
| `board` | 既有主持 `BoardView`，包含隐藏棋子；当前场景没有ready地图时为null |

地图优先选择战斗布局地图（战斗中）或当前所选地图（探索中），未选择时使用当前遭遇布局/观察地图；候选仅限当前场景ready地图，找不到匹配时取玩家版、再取其他可用版本。只读取既有图片和棋盘，不选择/切换服务器地图，不自动准备遭遇。

角色头像复用 `GET characters/{actorId}/portrait/image?portraitId=…&contentHash=…`，地图复用原 `map-image`；都由鉴权传输获取PNG再创建object URL，凭证不进入图片URL。没有头像时用名字首字；图片失败保留其余资料。

## 页面行为

主持剧情页以当前场景地图铺底，左侧为队伍和主持事项浮窗，右侧为剧情。队伍显示生命/临时生命、AC、状态、专注和有限资源，点击头像打开原角色资料窗。场景显示遭遇准备、隐藏单位与已发现者、NPC设定/秘密和DM备注。背景图居中铺满，顶部“查看完整地图”显示完整图片及全部棋子图例；隐藏者使用虚线标记与“未公开”说明。地图仍只读，不能拖动或提交棋盘操作。无地图时使用游戏端酒馆背景并显示无图说明，不放演示地图。

主持概览可收起，偏好保存在本机；收起隐藏队伍和场景资料，保留背景地图与真实待办。处理窗在中间地图区域打开，队伍和剧情仍可读，关闭后恢复偏好。剧情feed仍是唯一主阅读滚动，队伍和整个主持事项窗分别滚动。战斗时原战况入口、战况窗及 `combat-overview` 继续工作。

首次进入读取，此后复用 `dashboard-sync` 的更新回调，不新增轮询。背景与完整地图窗共用鉴权图片缓存。读取和图片持有本地代次；campaign、timeline、version必须与当前快照一致。切换/读档/离开或失去主持权限会清空私密内容及背景标记、关闭地图窗并释放图片。超前数据等待看板追上，旧数据及错误给出明确重试。玩家页不创建主持浮窗，也不发出此读取请求。

## 验证与复现

`DmOverviewTests` 覆盖主持/玩家权限、公开投影不含秘密/隐藏伏兵、当前场景隔离、无角色/无地图、战斗概览并存、数据库字节不变及零模型调用。`dm-sidebar.test.js` 覆盖传输验证、入口复用、处理栏让位/收起偏好、跨版本/战役/同版本不同时间线的迟到响应与销毁撤权。

隔离浏览器夹具：`dotnet run --project tests/DiceRealm.Tests -c Release -- --dm-overview-browser <新的状态文件路径>`。它使用测试账号、静态剧情、固定骰源和禁止调用的fake provider；写出临时服务地址及四种场景。创建 `<状态文件路径>.stop` 正常退出，写出 `.result` 记录调用数。真实截图、命令及结果见协作实现记录。
