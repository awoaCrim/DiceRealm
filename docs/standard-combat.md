# 标准2024战斗：当前执行范围

本模块是标准2024战斗的当前执行范围。权威实现位于 `server/DiceRealm.Server/Domain/StandardCombat/`；旧非致命模式及其历史回执不迁移。[旧战斗记录](combat.md)仍解释旧模式。

## 启用与内容

导入遭遇必须同时指定 `mode: "standard-2024"` 与 `nonlethal: false`。缺省Mode继续原非致命模式；单独false、未知mode或相互矛盾的字段均拒绝。内容仍由用户明确导入/启用，不内置默认战斗。无共享棋盘的旧遭遇保留7×5；绑定实际地图时每格5尺、每边最多32格、合计最多7名实际参与者，不省略队员或补造位置。玩家身份、内容版本、获胜后果和一次性奖励仍走原聚合。

敌人可明确选择 `tactic: "engage" | "withdraw"`。这是本场原创行为策略：接近有意识目标或撤离，不处决倒地队员、不追击区域外角色；不冒称官方怪物AI。全队倒地但仍有死亡豁免时继续处理；全队死亡/稳定后结束敌方推进。此封闭遭遇允许稳定角色显式等待恢复，不是对任意危险地点的安全承诺。

`cells` 可用blocked/difficult/half-cover/three-quarters-cover；不可穿越掩护/障碍格或斜穿障碍角。视线/掩护采用明示的格心射线和占格政策：全掩护拒绝直射，半/四分之三对当前攻击AC加2/5，居间生物算半掩护。无高度、黑暗或完整3D采样；运行时遭遇的有限隐匿见下节。Acid Splash的DEX豁免按区域中心至目标计算掩护+2/+5，有效Dodge给DEX优势；STR/CON豁免不加掩护。

## 已实际结算的规则

- 借机攻击在离开触及**之前**暂停，接受消耗反应，放弃不消耗；接受后的攻击、移动与后续NPC步骤只执行一次。失明、不可见、失能、撤离和Hadar禁止反应会阻止触发。
- 致命伤害、已记录永久抗性、临时HP、0HP昏迷/倒地/掉落、余伤即死、自然1/20死亡豁免、三成功稳定/三失败死亡、Help稳定和治疗解除0HP昏迷。治疗不复活Dead、不自动起身；稳定后明确等待1d4小时只恢复1HP，不当休息发资源。
- 12种基本近战武器：Club、Greatsword、Quarterstaff、Dagger、Mace、Longsword、Warhammer、Flail、Rapier、Shortsword、Greataxe、Maul。实际属性、熟练、Exhaustion、Heavy限制，以及Graze/GWF/Savage Attacker；新增精通见下表，未列精通不是拥有名称便自动执行。
- Extra Attack按实际职业级别，Fighter5/11/20与其他已支持职业5级；Action Surge每回合一次，不能使用Magic动作；Second Wind用Fighter等级。起身花半速度，倒地爬行加费；掉落物逐项保留坐标，拾回自身本格物品使用明确的Utilize动作，检查手持配置及护甲训练，不容许双手武器与盾并用或同时准备多把武器。

## 单武器精通

只有角色已取得对应武器精通且实际持握时开放。

| 精通 | 武器与行为 |
|---|---|
| Graze | Greatsword未命中造成攻击属性修正伤害，不掷伤害骰。 |
| Sap | Mace、Longsword、Flail命中后，目标下一次攻击劣势，至来源下回合开始；目标任何下一次攻击消耗此效果。 |
| Slow | Club的明确精通攻击（含借机）命中并实际造成伤害时速度减10尺，至来源下回合开始。重复来源独立到期但不叠加超过10尺；已用Dash的移动额度也随速度改变，不能保留原Dash增量。普通攻击可不采用。 |
| Vex | Rapier、Shortsword命中且造成伤害后，来源针对该目标下一次攻击优势（包括未命中的该次攻击也消耗），至来源下回合结束。 |
| Topple | Quarterstaff、Maul的明确精通攻击（含借机）命中后，目标CON vs 8+攻击属性修正+熟练，失败Prone。自作敌人缺CON来源时不给精通候选，普通攻击保留；NPC下回合可花半速度起身。 |

效果保存来源和准确回合边界，ActionSurge不重新发放。当前没有Push/Cleave/Nick、双武器/Light额外攻击、玩家投掷和远程武器流程，不把这些名称当作自动执行。它们与未覆盖的职业/子职业战斗特性继续明确裁定；本模块不声称完整实现全部D&D规则。

## 来源法术、专注与区域效果

候选复用角色实际准备/赠与/免费次数/普通和Pact法术位来源。来源不明、特性限定的`/feature`、仪式、不足资源和未满足成分不给自动执行候选。每个全局回合序号只能消耗一个法术位，免费来源次数不当作法术位。V/S法术保守要求未准备武器/盾的空手，War Caster可豁免手部要求；该特性的反应施法替代借机尚未实现。没有材料法术冒充已核组件。

| 法术 | 当前效果 |
|---|---|
| Shield | 命中骰已产生、伤害骰尚未产生时等待对应玩家；确认消费反应与确切来源，+5AC含原攻击，至自己下一回合开始。自然20仍命中。被Magic Missile选为目标也可触发；Shield免除该法术伤害。 |
| Blade Ward | 专注最多1分钟，每次针对自己的攻击骰减1d4，原骰/调整日志可查。 |
| Expeditious Retreat | 附赠施放立即Dash，专注最多10分钟，后续附赠Dash。 |
| Cure Wounds / Healing Word | 合法触碰/可见距离内的本人或同伴，2d8/2d4每slot级 + 该来源施法属性；已计Life3/6/17的相关治疗规则。不能复活、不会自动起身。 |
| Thunderclap | 格心5尺Emanation排除施法者，包含同伴；共享伤害一次，各目标CON，成功无伤害。按总等级5/11/17扩骰；记录100尺声响，不凭空生成区域外听众。 |
| Arms of Hadar | 格心10尺Emanation排除施法者，包含同伴；2d6 + 升环d6，同次共享伤害，各目标STR，成功半伤害，失败禁止反应到目标自己下一回合开始。 |
| Acid Splash | 60尺内明确格心，5尺Sphere含中心、施法者和同伴；按总等级5/11/17扩d6，DEX成功无伤害，应用从中心计算的掩护和Dodge。 |
| Magic Missile | 120尺内可见目标，3枚+升环枚数。先分配每枚或剩余全部，可撤销/取消，此时无动作/资源/骰点；这些未付费的开始、分配、撤销与取消保留在战斗记录里，但在叙述战斗中当场记为已叙述，不形成叙事节拍、不调用模型，也不挡住下一步选择，由付费施放后的叙述覆盖整轮飞弹。最终本人确认施放一次付费；所有受影响玩家的Shield决定完成前不骰、不扣任何目标HP。 |

区域候选在确认前披露完整目标/友伤。全掩护阻挡；受影响玩家逐席位确认豁免，后续目标不提前结算。伤害引起的专注豁免插在区域尾部前面；取消一次投掷请求不会撤销已施法或清除当前区域等待。

Magic Missile在全部Shield窗口关闭后，为每枚未被Shield阻挡的飞弹独立掷1d4+1 Force；所有飞弹在同一事务先造成伤害，然后等待仍能专注的玩家。2024共享伤害规则针对同时要求多个目标豁免的效果，本法术无豁免，故逐飞弹掷骰。每枚伤害分别触发CON是此实现明确的结算政策；任一专注失败后跳过余下已无专注的等待，失能者不额外掷CON。0HP时每枚仍独立计死亡失败，不能把整束合并成一次。Shield全部阻挡时不掷无用伤害骰。

专注在Character保存可空`concentration`（spellId/source/expiresAtSeconds），可跨战斗结束保留。重新施放专注替换原效果；可主动结束，无动作/骰点/退款；游戏时间推进到期、失能或死亡时结束。受伤（含临时HP吸收）后若仍可专注，DC=min(30,max(10,floor(伤害/2)))，本人CON豁免，War Caster优势。保存等待时既不掷专注骰，也不继续原移动。

## 敌人来源与明确豁免

自作敌人原基础字段仍由作者提供；区域效果需要明确 `savingThrows` 六项（strength/dexterity/constitution/intelligence/wisdom/charisma，-5..20）。不完整拒绝；完全缺省仍可做原基本近战，但针对它的区域自动候选被禁止，不猜+0。

标准遭遇也可绑定完整固定 `rulesId`：

- `xmm:zombie`：HP15/AC8/速度20/先攻-2；Slam +3、1d8+1 Bludgeoning；Poison伤害免疫；非Radiant、非重击降至0时，Undead Fortitude CON +3 vs DC5+本次伤害，成功落在1HP。
- `xmm:skeleton`：HP13/AC14/速度30/先攻+3；当前近战策略Shortsword +5、1d6+3 Piercing；Poison伤害免疫、Bludgeoning易伤。
- `xmm:goblin-warrior`（XMM p142）：HP10/AC15/速度30/先攻+2；Scimitar或Shortbow +4、1d6+2，短弓80/320尺。最终攻击有优势时额外1d4，重击加倍；优劣势抵消不加。`ranged`策略选择实际可射击的清醒目标，必要时沿现有寻路移动，Dash会消耗动作；离开可见敌人的触及时可用Nimble Escape附赠Disengage。借机仍用弯刀，没有自动Hide AI或完整NPC装备切换模拟。

绑定时所有上述基础数值必须相符，不能同时覆盖savingThrows，不能只用相似名字取得规则。已验证六属性豁免；Skeleton弓、黑暗视觉、语言、环境和未实现的条件来源不由这个平面近战策略模拟。没有完整记录的怪物不导入自动能力。

来源为固定修订`e5f3e77b303a92df10487207857200245e71957c`的本地完整XPHB/XMM。`scripts/verify_standard_combat_rules.py`验证原manifest、raw文件、book证据及预先存在的固定revision完整术语缓存SHA；缓存只允许primitive反序列化。全程0网络、0MCP、0模型。资料全文在忽略目录，不修改2619条中文运行包或自动对外分发。

## 运行时遭遇、隐匿与个人发现

Harness v35可依据当前非模型场景原文建立私有`Campaign.RuntimeEncounters`，不改导入Adventure或已有角色/棋子HP。每个场景至多一份，敌方定义与实际Board实例一一绑定；不允许复制、重建或复活。只能选择上述已核descriptor，模型不能提供怪物数值。

旧v35..41准备可显式指定本场square战术网格；这些冻结记录仍只读兼容。v42..45只使用当前局部战术图已保存的真实尺度并派生五尺格。v46将侦察准备与战术绑定拆开：必要侦察在已校准或未校准图上均可先保存真实单位和一次隐匿；实际开战前再为同一遭遇绑定可靠战术布局，不重建实体或重掷。具体字段、同图/跨图及失败恢复见[契约46](harness-runtime.md#侦察独立于地图校准契约46)。原PNG和尺度元数据不由遭遇工具修改。

Hide只支持明确四分之三/全掩护以及DM确认脱离敌方视线；v46侦察准备保存有依据的场景掩护，后续绑定战术布局时才校验当前仍隐匿单位的格心掩护。服务端为每个躲藏NPC掷一次DEX Stealth DC15并保存。地精修正+6；成功总值是后续Search依据，不能重准备或让模型另写DC。战前`check_request(encounterId,...)`沿本人主动确认或无骰被动察觉；战斗内`combat.search`消耗动作，由本人确认Wisdom (Perception)。检定显示本人骰点，不公开敌方阈值。逐敌比较没有共享固定DC时，双端显示“总值已记录 / 未列出固定 DC”，不能据此标成仍等DM或猜一个DC；真实等待以pending状态为准。

发现只写对应席位`KnownActors`；一人发现不代表其他人低结果也找到。按当前明确平面掩护政策，实际移动绕过掩体会更新能看见的席位并结束Hide，不把一次个人看见自动广播全队。NPC作出攻击骰时公开其棋子，再进入Shield/伤害等待；过去的私有日志不会随后来公开而重新发布。此处不是完整视觉/听觉/黑暗/潜行系统，也未建立通用叙事事实的个人知识库。

进入战斗仍等全部队员各自同意先攻后才统一掷骰；同种且相同修正的NPC共用一份先攻。显式惊讶只影响对应玩家的先攻劣势，没有惊讶轮；已发现伏兵的队员不能被当作未发现而设惊讶。

`CombatEntry.Audience`在首次写日志时冻结：null公开、空数组仅主持、非空为允许席位。Board、战斗快照、原结果、历史/日志/活动与模型回忆均按席位过滤；主持完整读取保留。普通模型战场上下文为本人可见投影，私有遭遇只能经`encounter_read`读取；日志序号间隙仍保留，不承诺消除全部推断侧信道。

## 自动死亡豁免与倒地回合推进

死亡豁免在0HP且未稳定角色的回合开始触发（同pin XPHB pp.28–29）；不要求先手选`combat.death_save`。普通服务端在结算事务结束后复用`PrepareAction`建立本人PendingRoll；新Harness合同52在该回合叙事提交/ack后建立，避免待投掷反过来阻止当前剧情交付。仍须本人通过`rolls/respond`确认才掷骰，其他席位只能看到等待，不能代投。

自动请求用战斗ID、TurnSerial和实际Actor确定内部requestId，每个回合至多建立一次；取消保留death wait，不因轮询/重启/后续补述自动重开已取消的同次请求，需玩家明确重新请求。原自然输入的本人待投掷绑定原intent并等待续接；结构化命令的叙述完成后，独立待投掷通过原确认端点继续，不伪造新自然输入。

`DeathSave`结算后仍0HP（含稳定或死亡）时排入原`advance`队列：逐行动叙事仍先交付死亡豁免结果，再推进下一单位/判断终局，不能让昏迷角色还要手动结束回合。自然20恢复1HP则不排advance，保留本回合预算，由本人选择后续行动。旧已提交结果、回执、骰点不重写；读取不修补或推进旧卡住记录。

回归：`StandardCombatHttpTests.AutomaticDeathSave*`（自动请求、本人确认、取消、跨席位、重开与原请求重放）、`CombatNarrationHttpTests.AutomaticDeathSaveContinuesNarratedBattle`（真实Pi+固定模型，按钮/自然输入两路，成功后下一轮再请求、冷恢复零调用/骰、自然20保留回合）。原生弹窗仍复用现有投掷UI，服务端测试不冒充Player验收。

## 提交、读取与恢复

所有动作使用原服务端行动/候选/本人确认端点和席位级回执；即使旧`/actions`也不能让新增标准投掷跳过PendingRoll。取消请求保留战斗触发；主输入含“好”不能替另一席位授权。Shield/确定性施法也通过这个确认队列；历史UI的“同意投掷”表示同意所列结算，不意味着Shield本身要掷骰。

网页玩家页 `/play/` 只显示快照给出的战斗选项：按钮与可走格来自 `availableActions`，价格与不可用原因来自 `actionOptions`，确认后经同一持久化原请求向 `actions/propose` 提交 kind/target；需要本人投掷的再走原确认卡。`combat.standard.wait` 指向本席位时（Shield/借机反应、飞弹分配、死亡豁免等）显示「需要你回应」卡，选项仍只来自快照；死亡豁免使用服务端自动建立的投掷请求。区域法术的选项另带可选 `area`（落点格、半径格数、此玩家所见的波及单位 id，仅快照有，模型候选不含）：Acid Splash 这类多落点法术在施法卡里只列一项，在地图上选中心，悬停显示范围与被波及者；选定后先出该落点的确认卡（服务端说明列出全部目标与友伤），再走服务端施法确认。格位叠在 `combat.boardLayout` 冻结的同一张已发布图上，该图不可读时只显示格位，不换图。页面细节见 V3 实现计划 网页第 4 步。

公开`combat.standard.wait`只含kind/actorId/targetId/description（opportunity、death、shield、concentration、area-save、missile-allocation）；私有`Campaign.StandardCombatFlow`保存剩余移动、命中、豁免及飞弹分配/反应/同时命中步骤，永不公开。命中待伤害、区域共享伤害、待确认豁免及动作/资源均随事件、回执原子提交。GET不推进。schema/引用/等待损坏在授权后拒绝并保留字节，不回填假流程。

已结束的历史战场可以保留，同时新成员在合法地点加入。`StandardCombatEngine.Choices` 对从未参与该已结束战场的新Actor返回无旧战斗选项，不查找不存在的历史单位，不重建/清空旧战场；历史参战者的稳定恢复等选项继续保留，活动战斗的原限制不变。`StandardCombatHttpTests.NewMemberAfterBattleKeepsHistoricalBoardAndJoinReplay`覆盖实际入房/审核、重启原请求重放与旧战场逐字不变。\n\nHarness只读工具在契约10引入：有界公共战场、精通来源/到期、当前等待与候选，并说明无费用分配与最终施法的区别。旧目录冻结，0..8不提供标准模式候选；v9保留原公共投影，不新增精通可选攻击、Acid Splash/Magic Missile候选；历史已保存回执不重写。普通战斗投影不包含胜利脚本、私有流或角色凭证；v35的私有遭遇入口另按上述合同提供DM准备依据。所有效果都由Domain计算，模型不能提交骰点/HP/资源补丁。
