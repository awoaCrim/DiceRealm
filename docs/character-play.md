# 角色工作区与主持调整

玩家在一个窗口阅读资料并选择具体行动；后端维护角色数值、任务状态与已知信息。检定由冒险流程按需触发，见 [按需投掷协议](contextual-rolls.md)。已经支持的效果见 [自然行动](natural-action-effects.md) 与 [标准战斗](standard-combat.md)；未实现的法术与能力效果仍明确保留裁定边界。

## 玩家如何使用

网页 `/play/`：左栏「角色」或 C 打开角色窗，I 直接到「背包」，「冒险手记」或 J 打开任务、人物、地点与线索。角色窗沿用工作台角色资料（人物、状态、能力、法术、背包），本人另有当前可做的操作：装备栏换装与穿戴、装备/卸下、同调、取出套装、受支持效果的「使用」、准备法术清单，以及有休息选择时的「恢复」页。按钮直接来自 `character/sheet` 的服务端选项，每次只发一条 `character/commands` 原请求（未确认时只重试原请求）；「成长」页读取成长机会、预览并确认升级（见[完整角色成长](character-advancement.md)）。尚无拖放与悬停提示卡。下文描述 Unity 客户端。

C 或点击队伍栏中自己的头像打开角色窗口，I 直接打开「背包」。页签为人物、状态、能力、法术、背包、恢复，无施法资料时不显示空法术页。资源与状态效果归入「状态」，准备清单归入法术，成长入口为“升级与成长 →”；不另设全局速查页。左侧滚动或中英文搜索，右侧查看资料与当前可做的操作；浏览、搜索、切分类、选择来源都不会提交。背包、已装槽与法术图标悬停显示名称、状态和简略属性；F1在原位置放大同一张提示卡并显示完整资料，不另开居中窗或压暗背景。按住Alt可将鼠标移入提示卡滚动、拖动标题移动，或拖动右下角调整大小；松开Alt且已离开原图标时简卡关闭，F1展开卡保持到×/Esc关闭。左侧普通文字列表不弹大提示。点击物品仍打开独立详情弹窗（普通装备与使用不在详情操作；同调是唯一例外）；未装备物品也可通过右键/菜单键/Shift+F10选择查看详情。右上角×或Esc返回并保留草稿（Esc依次关闭菜单、详情、窗口）；没有翻页、底部返回或常驻刷新按钮。多来源与多职业准备使用直接下拉；选择不会提交，选回“请选择”会清除已选命令，不再循环切换。画面与交互规则见 [Unity 前端规范](../.trellis/spec/frontend/unity.md)，直结算与休整见 [自然行动](natural-action-effects.md) 与 [队伍休整](../.trellis/spec/backend/party-rest.md)。

- **人物 / 状态**：「人物」只读显示身份、属性、技能、豁免、速度、体型、生命骰与货币；「状态」显示效果、时钟和资源余量。没有任意掷骰、扣资源或勾任务入口。
- **法术**：同一法术只需找一次，阅读其资料并显式选择职业/免费次数/法术位/仪式或受支持自动行动。多个来源不代选；精确来源和成本来自服务器。当前快捷施法只提供服务端明确支持的可执行效果，确认后扣除确切来源资源并应用效果；其他法术资料仍可读，使用意图在冒险输入中补充目标和方式，不再提供通用扣资源后请求裁定的按钮。旧已冻结请求和回执保留原语义。
- **背包**：可滚动物品图标格显示数量、装备状态，名称在悬停卡查看；不造容量或未知物品图标。未装备物品右键只有“装备”和“查看详情”，已装备物品右键只有“卸下”，不可用时禁用并说明原因。有多个合法位置时点击装备再选择；也可直接将物品拖到护甲、近战/远程主副手或相应穿戴槽，松开即提交，Esc取消拖动。错误位置和装备冲突不会擅自换槽或先卸下其他物品。独立详情弹窗展示物品资料，不再提供通用“选择本次用法”、装备或物品使用确认；仅需同调物品提供带实际1小时成本的同调/结束同调操作。物品使用在主行动输入说明。装备冲突、耗时、AC、速度与隐匿影响由服务端检查，不提供数量补记工具。
- **准备法术**：长休后一次提交完整准备清单，遵循服务器返回的选项和替换限制。准备草稿与已生效清单分开，过期时明确提示重新选择。
- **能力与恢复**：原始能力条目仅供阅读，没有通用“请求能力裁定”按钮。使用意图在冒险输入中表达；服务端明确提供的合法行动仍可预览与确认。只读信息不显示空操作按钮。全队休整由主持发起（玩家自行发起返回 `rest_host_required`）；本人同调使用独立的个人专注短休，不替队友休整，「恢复」页只在实际短休之后让玩家选择本人的生命骰和奥术回想，生命骰仍须本人确认；长休后的准备/来源选择也各自由本人完成。

打开时立即显示已知资料，随后加载最新可操作选项；角色页打开期间随快照版本变化自动读取。读取失败可继续阅读，且仅此时显示“重试读取”，不会后台无限重试。未确认的命令独立显示“重试原请求”，不自动重发。旧版本、换席位、未确认请求或待投掷期间不能用旧按钮继续操作。所有数值与实际结果仍由服务器保存。

背包上方同时显示护甲、近战主手/副手、远程主手/副手。例如近战主手短剑、副手匕首与远程短弓可以同时配置。装备带右侧不再展示当前持用标题、近远切换/握持按钮与说明文字；既有服务器组合/握持状态仍保留，不自动改写。格子“装”表示已配置，“用”表示当前持握，主副手可同时显示“用”。空槽点击或右键可选择该槽物品；已装槽点击仍打开物品详情，右键只显示“卸下”。槽位卸下只清该槽，背包卸下清除该物品的所有装备位置。双手武器在副手显示半透明图标及“双手”，不代表第二件库存；对占位图卸下会清空同组主手。

双手武器攻击时占两手；两用武器的一手/双手握持仍由服务器记录，已支持的近战结算据此使用对应伤害骰，双手握持不能再持盾或副手武器。轻型不是放入副手的必要条件，也不意味着系统已实现额外攻击。盾只有实际持握才增加AC，切组造成穿/脱盾各耗6秒；护甲训练与原穿卸耗时保留。同组主副手用同ID物品需两件，跨组可共用同一件。标准战斗掉落/拾回分别记录实际手槽，背负的另一组不掉落。双持额外攻击、未支持的远程/投掷/装填自动结算仍不在本轮范围内。

新建角色由服务端建立初始配置；旧角色只读推导原持用武器及盾，读取不改存档，下一次明确换装才保存装备栏。没有新版装备栏的旧服务响应仍按equipment投影提供装备/卸下，不猜测槽位。

直接换装、切近战/远程与握持不会作为玩家发言和 DM 回复刷入游戏端或工作台剧情，已保存的旧换装记录也不在剧情显示。角色面板就近显示“装备已更新”，有实际耗时才附秒数，失败时显示原因；不重复播报“经过 0 秒”“未自动攻击”。底层事件、原回执与冒险日志完整保留；通过自然语言提出的行动及其叙事不受此过滤影响。

背包详情按服务器目录身份读取本地中文规则库的完整物品属性（如类型、价格、重量、伤害、射程与特性），不根据可修改的显示名猜规则。没有匹配正文时明确显示资料缺口；规则可读不新增物品使用能力。金币、银币、铜币的运行库存ID与建卡目录ID使用同一图标。

## 完整穿戴与同调

普通长袍（dnd2024 / XPHB p228）现可在背包右键装备或拖入“衣着”槽，也可原路卸下。它是衣物，不占护甲身份、不提供AC或同调能力；多件独立衣物使用动态衣着槽，不静默替换另一件。精确旧ID与显式规则身份的兼容见[穿戴契约](client-contract.md#wearables-and-attunement)。MCP对Robe未命中，依据固定revision的本地 `items.json` 取证，不能称为MCP成功。

背包上方在原护甲与近远四手之外，增加头部、披风、手部、护腕、足部和饰品位置。护甲仍是一整套，不按头胸手脚分别叠AC；手套与护腕独立，成对靴/手套按一件完整物品管理。戒指、颈饰等按实际物品展示，**不设BG3式两枚戒指上限**；装备带超宽可横向滚动，键盘选择会滚到对应位置。普通穿戴/卸下可用拖动或原右键菜单，不重复确认、不自动挤走冲突物品。

- **穿戴不等于同调**：详情显示已穿戴、未同调、实际生效或受限原因；装备区显示已用同调 `x / 3`。未穿戴也可同调，但物品效果仍检查具体穿戴条件；卸下不会解除同调。
- **同调/结束同调**：在物品详情明确选择，每次完成本人专注该物品的1小时短休。要求安全休整地点、无战斗/失能等实际阻塞；不额外申请主持批准、不借用旧短休余额。正常恢复本人的短休资源并开放生命骰选择，不自动回血、不消耗生命骰、不代队友恢复。冒险时间原子推进3600秒，不是现实等待1小时的计时器。
- **上限与结束**：最多3件，同种物品不能同调多个副本。真实死亡（不是仅0 HP）或他人对同一实物同调会结束原关系。丢失库存不凭空当成超距24小时，状态页“同调”组仍可结束该记录，无假库存；目前没有距离追踪，不自动判断“超过100尺24小时”。首批目录没有诅咒或额外职业/物种资格。
- **简明状态与AC**：主界面右栏只列护甲、当前/备用组合和真实待处理问题，不堆完整穿戴清单。护甲数值提示、人物页“防御来源”及工作台“防御与装备”读取服务端同一实际计算来源，不由客户端拼加值。

首批接入12件2024魔法物品。下表前五件已自动结算；其余七件可穿戴及按规则同调，但复杂能力**尚未自动结算**，详情明确标注，不能当作已获得相应属性/视觉/呼吸或施法能力。

| 物品 | 自动效果与条件 |
|---|---|
| 防护斗篷（Cloak of Protection） | 穿戴且同调：AC +1、所有豁免 +1（包括死亡豁免） |
| 防护戒指（Ring of Protection） | 穿戴且同调：AC +1、所有豁免 +1（包括死亡豁免） |
| 防御护腕（Bracers of Defense） | 穿戴且同调、未穿护甲且未实际持盾：AC +2 |
| 精灵靴（Boots of Elvenkind） | 穿戴无需同调：敏捷（隐匿）检定优势，脚步无声 |
| 盗窃手套（Gloves of Thievery） | 穿戴无需同调：敏捷（巧手）检定 +5；2024不附加盗贼工具 +5 |
| 智力头带、食人魔力量护手、健康护符、矮人腰带、易容帽、夜视镜、适应项链 | 穿戴/同调记录可用；各自复杂能力尚未自动结算，不改相应属性或伪称全面生效 |

规则身份取显式 `Item.rulesId`（`magic_item:xdmg:<slug>`），不按显示名称猜测。新永久魔法物品由v21结构化获物建立独立实物ID，成对物品数量为1；旧存档不批量迁移，主持只补同名文字物品不会自动授予能力，旧冻结行动目录和回执不升级。规则核验使用明确 `dnd2024` 的本地MCP及同固定来源的XPHB章节；协议见[穿戴与同调](client-contract.md#wearables-and-attunement)，执行边界见[Harness契约21](harness-runtime.md#完整穿戴与同调契约21)。

准备状态独立保存在 `playState`，不会修改原始 `build` 取得记录。DM短休/长休恢复全队有效成员的相应资源，共享时间只推进一次（1小时/8小时）；短休不自动回血或消耗生命骰。个人选择只改本人的来源/资源，不能关闭队友窗口。资源恢复策略包括短休全部、短休一次、长休全部与仅主持调整。新增的主持计数器不因休息被自动充满。2024 长休清除临时 HP，并使 Exhaustion 降低一级。

归档、内容未启用或旧自动遭遇进行中会禁止普通角色操作。零 HP、失能类状态与 Exhaustion 也会限制相应操作；死亡豁免、复苏、完整状态连带效果和临时加值仍需人工处理。法术用途是项目编写的简要说明，不是完整规则正文或效果执行承诺。

### 主持如何落实裁定

在工作台「剧情」页右栏的队伍状态卡上打开调整（主持可见）：选择仍有效的角色，填写变更行、理由与规则来源或本场约定，先查看服务端实际预览，再确认保存。可以独立调整，也可关联同角色、同场景且尚未落实效果的待裁定或已记录检定。

允许记录最终伤害、恢复或校正当前 HP、替换临时 HP、Exhaustion、列出的状态、已有资源当前值和物品数量。也可新增仅手工恢复的主持计数器，或只记录名称与数量的物品。新增物品不会从名字推导护甲或武器效果。

伤害先扣临时 HP，再扣普通 HP，输入的是主持核算后的最终数额，不重复应用抗性。治疗不超过生命上限。临时 HP 是替换，不叠加。不能修改属性、等级、生命上限、建卡来源、角色所有权或剧情事实；理由中的文字也不会被解释为任意状态补丁。

一次调整中的所有行与事件、版本和请求回执一起原子保存。预览不掷骰、不写存档。任何表单修改、目标切换或版本变化都会使旧预览失效；确认后响应丢失时，工作台保留原 endpoint、requestId、版本和请求内容，刷新后仍重放原请求，不另造一次伤害。

关联记录保留变更前后值、理由、来源和操作席位。已完成的检定不会被新调整覆盖；同一裁定不能重复落实效果。玩家已经记录的法术或能力资源不会由主持入口再次自动扣除。若主持拒绝先前使用，需要通过新的明确调整退还资源，不能靠改写旧审计记录回滚。

### 实现与来源

[CharacterPlayEngine](../server/DiceRealm.Server/Domain/CharacterPlay/CharacterPlayEngine.cs) 共用选项投影和执行校验；[CharacterAdjustments](../server/DiceRealm.Server/Domain/CharacterPlay/CharacterAdjustments.cs) 共用纯计算的预览与保存逻辑。[CharacterPlayService](../server/DiceRealm.Server/Application/CharacterPlayService.cs) 负责身份、版本、回执和事务接入。Unity 操作窗口 不计算权威角色数值；[工作台调整请求](../client-workbench/src/api.js) 只编码协议列出的变更字段，不接受任意 JSON 补丁。协议见 [客户端协议](client-contract.md#character-use-and-host-adjustments)。

规则取证脚本 使用本地 stdio D&D MCP，明确指定 `dnd2024` / `XPHB`，并用同一固定 revision 的职业、物种、专长、法术与书籍数据补充核对。法术速查由 生成器 和 用途摘要 生成；完整原文只留在本机取证目录，没有嵌入公开 Player。没有跨版本回退。
