# 已确认的世界路线与地图关联信息

服务端已能把公开的独立地点记录转为可旅行地点，并维护有方向、明确旅行时间、可开闭的路线。模型提议后使用现有本人确认流程；不要求 DM 再录入同一地点或路线。已导入剧情的任务、人物、阵营、地点变体和路线条件仍由原 ContentRuntime 根据已确认事实自动投影，不重复执行奖励。

## 玩家流程

普通叙事可以记录地点，但文字记录不会自动开路。路线需要明确的端点、每次旅行秒数、方向和公开依据；距离或时间不清楚时先询问玩家。提议会显示「确认世界路线」，列出方向、时间与依据。此时没有新增地点、路线、移动、时间或资源消耗。本人确认后维护路线；继续处理或另行旅行才实际出发。取消和过期提议不能建立路线。

独立地点沿用原公开记录的名称和说明，后续纠错即时反映。没有图面位置依据就保持 `unlocated=true`；没有安全休息、遭遇或奖励定义，不猜测赋予这些资格。地点记录被隐藏后不再作为可旅行目的地；如果队伍已在该地点，则用中性名称显示，并允许沿已确认路线返回公开地点，避免无法离开。

新路线不能覆盖任何已导入端点对，包括目前关闭、有条件或单向的路线。不能用一个同名新地点替代隐藏的导入地点绕过限制。原剧本文档不修改，旧人物、任务、奖励和事实操作保持原权限。

## 工具合同与保存

路线工具在契约6加入，分页规模在7扩充；当前新运行使用16，旧工具目录原文与schema冻结。v5的原始目录hash来自改动前隔离程序集，已写入回归，不从新代码重新生成期望值。

- `world_routes({offset=0,limit=8})`：当前地点关联的公开动态路线；limit 1..16，offset 0..2048，同版本分页。返回端点、当前标题、seconds、bidirectional、open、revision、公开reason与updatedSequence。只读，不授予行动、地点或记忆引用。
- `world_route_propose({routeId,sceneId,memoryId,seconds,bidirectional,open,reason})`：所有字段必填。必须先在本run当前版本、最近一次写入/等待续接后执行 `context_read`。新路线routeId空，sceneId与memoryId二选一；sceneId取该次公开knownScenes，memoryId必须是本run实际读过的独立公开place。已有SceneId的place应使用已有场景，不另造地点。修改路线用routeId，其他两ID留空，端点不可变。seconds 1..604800，reason 1..500字符。
- 提议返回原intent等待；确认仍是 `POST intents/respond` 的 `choose/cancel/ruling`，客户端只提交冻结option ID。所有已批准席位可处理自己的日常世界行动，不新增主持维护队列。

私有 `Campaign.WorldAtlas` 可空，schema1，保存 `WorldPlace(Id,MemoryId)` 与 `WorldRoute`，分别最多512和2048。当前新库SQLite user_version为2，旧库首次授权写迁移；世界信息独立行、索引和备份合同见[索引存储](world-memory-storage.md)。新字段缺省不分配；采用atlas后的存档需匹配新版，不能用忽略字段的旧程序当作安全回滚。授权读取和提交前检查结构、引用、重复端点对、计数、时间和来源序号，损坏报 `invalid_world_atlas` 并保留原件。

`Adventure.Exits` 是合法旅行的合并入口；显示成本与实际旅行共用。地图可以保留从已访问地点出发的当前合法拓扑，只有当前位置的合法出边可旅行。读地图不写入“观察到的路线”事件，也不重复执行世界后果。

## 自动图面关联信息

地图响应新增 `automaticMarkers`，与人工 `markers` 分开。服务器将公开记忆的明确SceneId关联到该图已有的地点标记，沿用该地点标记的实际归一坐标，不猜坐标、不把文字距离换成像素。没有锚点、未知地点、隐藏/主持/未抵达信息不生成玩家关联标记；私有地图和锚点权限仍执行。

先在已知地点的公开记录中选取最多128个最近更新的关联候选，再与该图锚点匹配；每图最多返回128个自动信息标记，按更新时间和ID稳定排序。ID由地点标记ID与记忆ID确定；修订名称、正文、状态会更新同一标记，不改变地图版本、发布状态、图片哈希或产生生成请求。自动标记只读，不能写回人工标记接口，也不能授权旅行。它表示公开记录关联的地点，不代表人物实时追踪。

工作台显示两类标记，编辑器仅提交人工列表；Unity地图同样只读显示自动标记。

## 测试

`WorldRouteTests`/`WorldMapTests`覆盖纯计划、引用/封锁拒绝、单向/开闭、纠错与隐藏、多人本人确认、并发、重开、取消/过期、坏存档保留及独立地图记录字节不变。浏览器验证使用本地fake模型与明确标记的QA图片，不证明供应商语言或美术质量。

大规模世界信息（8192条权威行与索引、256条快照窗口、公共/主持分页读取、工具7和迁移备份）见[详细合同](world-memory-storage.md)。未列规则仍不支持。
