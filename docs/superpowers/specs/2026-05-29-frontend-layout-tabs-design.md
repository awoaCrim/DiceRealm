# 前端布局与预设块折叠设计

## 目标

优化现有前端界面的清晰度。核心改动是把主持人管理页改成按任务分组的标签页，并让预设编辑器中的提示词块可以折叠。

## 范围

本次包含：
- 保留当前深色 DND 风格。
- 优化首页、玩家页、管理页的布局清晰度。
- 将管理页从单条长页面改为任务导向的标签页。
- 让预设编辑器中的提示词块可折叠。
- 更新现有中文 UI smoke test，并增加标签页和预设块折叠的聚焦测试。
- 实现后用浏览器手工验证首页、玩家页、管理页标签页和预设块折叠。

本次不包含：
- 手机端/窄屏专项适配。
- 拖拽排序提示词块。
- 引入 UI 组件库。
- 修改后端 API、数据库 schema 或 SillyTavern 导入逻辑。
- 从零重做视觉主题。

## 整体布局

所有页面继续使用当前奇幻深色主题，但页面结构要更清晰：

1. 页面标题区
   - 首页：产品名和创建房间说明。
   - 玩家页：玩家/房间/回合状态摘要。
   - 管理页：房间名、当前回合、房间状态。

2. 卡片内容区
   - 继续使用并微调现有 `.card` 和 `.subcard` 模式。
   - 表单控件保持统一视觉。
   - 多个相关按钮使用按钮组样式，减少操作混杂。
   - 除非新布局必须调整标签，否则保留现有中文文案。

3. 管理页任务标签页
   - 管理页不再把所有模块纵向堆在一个长页面里。
   - 标签页只为桌面端优化；不做手机端专项设计。
   - 可以保留现有基础响应式 CSS，但不要新增手机端特定交互或布局。

## 管理页标签页

管理页使用本地 React state 记录当前标签页，不改变 URL 路由。

标签页包括：

- `总览`
  - 玩家列表。
  - 当前已提交行动。
  - 处理本回合按钮。
  - AI 错误。
  - 全部日志列表。

- `AI 约束`
  - AI 约束 textarea。
  - 保存 AI 约束按钮。
  - 预览 AI 请求按钮。
  - structured prompt preview 面板。

- `资源`
  - 全局资源导入面板。
  - 房间资源绑定面板。

- `预设`
  - 预设列表。
  - 当前启用预设标识。
  - 预设编辑区。
  - 可折叠提示词块编辑器。

- `世界书`
  - 原生世界书创建。
  - 原生世界书条目创建。
  - 现有原生世界书条目列表。

切换标签页只改变可见 UI，不触发额外 API 请求，不清空未保存草稿。

## 预设块折叠行为

管理员点击 `编辑预设` 后，预设编辑器中的每个提示词块都显示为可折叠项。

折叠状态标题显示：
- 块名称。
- 注入位置。
- role。
- 是否启用。
- 排序值。

交互行为：
- 进入预设编辑模式时，所有已有提示词块默认折叠。
- 一次只展开一个提示词块。
- 点击折叠标题：
  - 如果该块当前折叠，则展开该块，并收起其他块。
  - 如果该块当前展开，则收起该块，使所有块都处于折叠状态。
- 展开后显示现有可编辑字段：
  - 块名称。
  - 注入位置。
  - 排序。
  - 启用 checkbox。
  - 内容 textarea。
- 点击 `新增提示词块` 后，新块自动展开，其他块收起。
- 点击 `保存预设` 成功后，退出编辑区，回到预设列表状态。
- 排序继续使用现有数字输入，不添加拖拽排序。

## 组件边界

实现应保持轻量，避免大规模重构。

推荐边界：
- `AdminPage` 继续作为页面协调者，负责数据加载、mutation 回调和当前 tab state。
- 如果 `AdminPage` 变得过长，可以提取小组件：
  - `AdminTabs`：渲染 tab 按钮和 active 状态。
  - `PresetBlockEditor`：渲染单个可折叠提示词块。
- 现有独立组件继续保留：
  - `ResourceImportPanel`。
  - `RoomResourceBindingsPanel`。
  - `PromptPreviewPanel`。

不要把后端逻辑移入 UI 组件。除非测试暴露直接需要，否则不要修改 API helper 签名。

## 数据流

- 管理页加载继续基于 `getAdminState(roomId)` 和 `subscribeRoom(roomId, refresh)`。
- 标签页只影响 UI 可见性，不改变服务端状态。
- 必须保留已有 AI 约束 dirty 保护，后台 refresh 不能覆盖未保存的 AI 约束草稿。
- 必须保留已有房间资源绑定 dirty 保护，后台 refresh 不能覆盖未保存的绑定选择。
- 预设编辑继续使用现有 `presetDraft` 本地 state。
- 预设块展开状态使用本地 UI state。
- 展开状态优先使用 block id 作为 key；对于新增且尚无 id 的块，可以使用当前数组 index 作为 fallback。
- 新增提示词块时，同时更新 `presetDraft` 并把新块设为当前展开块。

## 错误处理

- 保留 `AdminPage` 和子组件现有 `setError` 错误显示流程。
- 切换标签页不清空未保存草稿。
- 切换标签页不触发额外 API 请求。
- 保存预设失败时，保持编辑器可见，并保留当前展开块，方便用户修改后重试。
- AI prompt preview 失败时，使用现有错误显示流程，并留在 `AI 约束` 标签页。

## 样式

按需增加少量 CSS 工具类：
- `.tabs`：横向标签页容器。
- `.tab-button` 和 active 状态：标签页按钮。
- `.button-row`：相关操作按钮组。
- `.section-header`：标题和说明组合。
- `.collapsible-header` / `.collapsible-body`：预设折叠块。
- `.summary-row` / `.meta-row`：紧凑展示块元信息。

样式目标是提升层级和可读性，不更换主题，不新增依赖。

## 测试

更新或新增测试覆盖：
- 管理页渲染 tab 按钮：`总览`、`AI 约束`、`资源`、`预设`、`世界书`。
- 点击 `资源` 后显示全局资源导入和房间资源绑定 UI。
- 点击 `预设` 后显示预设管理 UI。
- 点击 `编辑预设` 后显示折叠的提示词块标题。
- 点击提示词块标题可以展开该块，再次点击可以收起。
- 展开一个提示词块会收起其他提示词块。
- 点击 `新增提示词块` 后，新块自动展开。

保留现有 API helper 测试和中文 UI 文案测试。不添加过度的视觉快照测试。

## 手工验证

实现后需要：
- 运行完整测试、typecheck、build。
- 启动 dev server 并用浏览器验证：
  - 首页仍能创建房间。
  - 创建玩家链接后，玩家页仍能打开并显示玩家状态。
  - 管理页标签页可正常切换。
  - `资源` 标签页包含导入和绑定面板。
  - `AI 约束` 标签页包含 prompt preview。
  - `预设` 标签页包含预设编辑器。
  - 预设块可以展开和收起。

不做手机布局验证。

## 完成标准

- 管理页不再是单条长页面，主要工作流被拆到标签页中。
- 预设提示词块可折叠，降低编辑器纵向拥挤感。
- 现有 SillyTavern 独立资源导入和绑定行为仍正常。
- 现有 AI 约束 dirty 保护和资源绑定 dirty 保护仍正常。
- 没有新增手机端专项范围。
- 测试、typecheck、build 和浏览器手工验证全部通过。
