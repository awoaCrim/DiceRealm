# 本地中文核心规则库

本任务目标是 **2024 三核心书 XPHB/XDMG/XMM 的本地完整中文资料**，不包括扩展，不用 2014 补缺。运行时不调用 D&D MCP、下载资料或即时翻译。维护资料与游戏结算分开：读到火球术不代表角色已取得、准备或有资源施放，更不代表服务器已支持其全部效果。

## 当前覆盖与文件

当前已取证的固定本地源含 **2685 个实体**，不是三本书的完整章节。可运行中文包已有 **2619 条完整可分页正文**：此前的391个法术、18个状态、485个怪物，加上本批1725个角色／装备／魔法物品等条目。角色和物品8批译文已完成、复核并合并，不再处于待翻译状态。其余66条已分开处理：27条不作为独立规则选项（22条纯名称／分类／字体索引、5条未绑定物品模板），39条仍待补源（35个怪物缺巢穴／区域效果原文、4个物品族缺变体）。排除项不再混入待译清单。`sourceComplete` 和 `translationComplete` 均为 false；完整库任务保留进行中，不把现有可发布条目全部汉化等同于三本书完整。

- `scripts/local_rules/`：离线维护代码与测试，可审查的项目源码。
- `local-rules/raw/sources/` 和 `raw/source-manifest.json`：固定原始定义及逐文件证据，不覆盖已有不同内容。
- `local-rules/translations/`：按稳定 ID、sourceHash 和叶子路径绑定的译文。
- `local-rules/library/`：原始 definition、译文状态、缺失单元、保真问题及完整文本；`publication` 另记独立发布资格与排除原因，分类计数区分 `excludedCount` 和 `blockedCount`。它是可重新构建的维护投影。
- `local-rules/reference/`：只读既有中文译名与角色身份对照资料，不是全文完成证明。
- `local-rules/dist/`：`active.json` 指向一个 `{sha256}.json` 不可变运行包；更新后保留旧版本。

`local-rules/` 已整体忽略，不嵌入匿名静态资源、不随默认服务包公开分发。原始数据来自用户现有本地归档；工具代码的开源许可不代表书籍内容取得公开再分发许可。`old.zip`、`.reference`、正式存档和日常服务不被改写。

## 离线维护命令

从项目根执行，Python 3.11+，无需启动游戏或 D&D MCP：

```bash
# 首次提取必须明确指定本地归档；仅解码固定 revision 的32个规则缓存，不解包全树
python -m scripts.local_rules.cli --archive old.zip extract
# 验证原始证据、组装维护库、校验并发布新的不可变包
python -m scripts.local_rules.cli build
# 按 active 验证文件名、bytes hash、严格 JSON 和 schema
python -m scripts.local_rules.cli verify
# 当前分类、状态及缺口报告（具体输出参数见 --help）
python -m scripts.local_rules.cli report --help
```

`--data-root` 可指定隔离数据目录，各子目录也可显式覆盖；默认是项目根 `local-rules`，不依赖执行时 cwd。`verify --version <64位小写hash>` 可核验保留的旧版本。更换 active 不会让已有运行自动换译本；回退应明确选择已经验证的旧 hash，不删新版本或改写历史回执。

提取和后续加载固定 revision `e5f3e77b303a92df10487207857200245e71957c`。发现清单和 manifest 有独立代码 pin；每份原始 bytes、payload canonical hash、输出字节数和精确文件集合都复核。不信任可同时被修改的文件与旁边的自签 manifest；不执行 pickle 类/函数。读取在分配前限制大小，文件在读取期间增长也有上限。

不可变原始文件和运行包先写同目录唯一临时文件、flush/fsync，再用原子 create-no-replace 发布；已存在只允许相同内容，不用先 `exists` 再覆盖。文件系统不支持所需原子发布时明确失败。只有 active 指针允许原子替换，切换前再次验证目标。此机制防并发维护覆盖，不承诺任意攻击者控制文件系统时的完整隔离或跨文件数据库事务。

## 翻译与保真标准

当前译文由代理整理，`translationStatus="translated"` **不表示人工逐条校审**。构建检查 sourceHash、全部单元键、未知 AST、残留标签、数字/骰式/单位与完整分页；这些检查也不证明自然语言条件在语义上完全正确。维护器额外在标签解析后扫描英文自然词，允许明确规则缩写、骰式和纯数值表格；一段文字含有汉字不等于已汉化。该机械泄漏门禁是构建侧的更严格检查，C#运行加载并不重新做翻译审校。

法术头部保留施法时间数字、多种施法选项、范围形状、自身原点、永久结束条件；正文保留材料、反应触发、升环、列表和表格。未知结构必须记录并阻止该条成为完整正文，不把半个 header 或中英混合摘要算完成。既有中文译名证据有固定bytes pin和严格schema；有效sourceHash绑定译文优先，不允许修改旧译名文件却沿用原文hash冒充同一译本。名称索引按引用类别/来源区分同名装备与法术，歧义必须拒绝而不是任取首项。中文显示名、原名和稳定身份分开维护；英文 canonicalName 仅供内部身份/检索，不要求改成中文 ID。原始定义中的英文别名（如Firebolt、Luckstone）也作为内部检索键保留，不能丢弃，查询投影不输出aliases/canonicalName。构建侧只对sourceHash绑定原文中的检索别名允许英语；中文显示名、正文和代理自行添加的中文别名仍过原语言门禁。独立包验证检查别名形状/长度/标签，不假装没有原始层也能重做该来源证明。

本批审查抽检火球术、反制法术、祈愿术、月光束、传送术、石墙术；发现并修复施法时间“1”遗漏、锥形/直线等范围丢失、永久结束条件泛化、祈愿术列表拆项，以及两条锥形译文错误使用“半径”。这是定向抽检，不是 409 条人工逐条认证。怪物批次已按原文修正条件抗性与成员的关联、动作／附赠动作／反应／传奇动作归类、每日各法术次数、变体头部标签和龙族灵体5种本地变体。鬼婆集会魔法正文明确使用法术正常施法时间，保留为特性而不误作一个动作。数值完整但没有自然语言段落的巨蝇统计卡可以发布；缺35组实体所引用巢穴原文的记录仍阻塞。译文另定向核对二阶段豁免、类人生物类型、命中或未命中、专注、多重攻击与召唤公式，并修正发现的15个歧义／类型单元；这仍不是全部6336怪物单元人工逐条认证。其他新增类别须先证明完整字段/引用/嵌套结构覆盖，再批量翻译；不得只将类别加入白名单就宣布完成。

角色/物品分类使用同一份已验证raw建立 `RenderContext`，按stable ID传入角色目录和不可变物品引用索引。导出单元、结构检查、译文键检查、最终正文均走同一个分类分派；角色内嵌武器使用同一物品树，不拿名字代替数据块。缺上下文/错源/歧义引用显式阻断，不能从可变library投影或全局缓存回退。完整统计卡允许零自然语言叶子，名称索引不算完整正文。

物品的 `ability`、`bonus*`、`modifySpeed` 等索引可能是有条件效果，`charges` 也可能代表星辰法袍上的星星或每日使用次数。构建只审核这些派生索引，以完整正文或已验证变体保留资源身份、费用、恢复条件，不凭字段名生成无条件属性或统一“充能”。武器属性与精通引用展开实际全文；角色前置条件的OR/AND、每法术次数、筛选逻辑和引用保留的消耗均有独立处理。未绑定参数的物品模板不能作为独立完整规则发布，其原始定义仍保留；具体物品会在引用上下文中展开。职业成长按数字等级排序，已核核心资源的缺省数量和单位保留，内部显示标记不投影给玩家。这些类别中通过结构与译文检查的1725条已纳入活动包。

本批角色/物品维护了7892个译文单元。独立语义审查覆盖角色35实体/533对、物品32实体/425对，不代表全库逐条人工认证。已修巨武大师两项触发的近战武器限制、削弱精通使用者下回合截止、全掩护条件、艾恩石总环阶容量与穿戴状态；相同源文本在其他条目中的重复问题也已修复。编号`331422-W`完整保留，重装/装填与武器多用术语分开，跨批名称变体可检索。Shield法术显示名由误用的“盾牌”改为“护盾术”，旧名仅保留检索兼容；实体ID、原始定义和此前894条正文不变，旧包不覆盖。

## 运行接入与查询

本机管理员显式设置 `LocalRules:Directory`（环境变量 `LocalRules__Directory`）指向 `local-rules/dist`。未配置时规则库不可用，不影响无关旧战役；配置损坏时在新运行启动、模型外发之前拒绝。不修改现有日常服务配置或旧包。

工具契约4提供 `rules_search` 与 `rules_read`；参数、错误与回放合同只维护在 [运行文档](harness-runtime.md#本地中文规则查读契约4)。新 Run 固定包 hash，首次上下文不注入整库。工具结果不包含规则书名、页码或源修订；双端隐藏这些出处，但保留能力取得途径、资源成本、检定结果及 DM 手填裁定依据。

运行包 schema1 拒绝未知/重复字段、错误 hash、非固定 revision、缺少任一分类计数、未解析标记和自报全量完成。当前没有经过独立审核的三核心完整 manifest，**任一 complete=true 都拒绝**；未来开启全量声明必须先新增实际完整源证据和对应校验，不能只改布尔值。
