# 主持提示词作者稿

`dm-core.md` 是供使用者审阅、编辑和明确导入的通用主持部分，不是服务器默认提示词，也不会自动追加到模型请求。运行中的房间、已冻结回合和已安装冒险包不因这个文件变化而更新。

`dm-combat.md` 是随服务端嵌入的默认战斗主持提示词（契约54起）。房间未设置自定义战斗正文时，新战斗自动使用这份独立原文；工作台「提示词 → 战斗主持」可查看、修改，清空并保存恢复默认。已有自定义稿优先，探索正文不拼入战斗；已开始的战斗保留冻结原文。使用当前真实状态、个人发现和一次归还，不重建遭遇或重掷。自动回归不代表真实供应商文风已经验收。

组织方式：

- 通用稿负责主持权限、玩家自主权、事实与结算、知识边界及叙事组织。
- 参数、合法来源、确认和成功/等待/失败由当前工具合同定义；作者稿不扩张执行能力。
- 当前单位、位置、动作、地图与待处理事项使用每轮实际状态，不在作者稿中预填。
- 冒险专属来源、条件路线、发现标记和更严格的地图要求，保留在该冒险的附加块。

使用时先审阅通用稿和目标冒险附加块，再将合并后的完整文本作为明确的 preset 内容导入；不要只用通用稿覆盖整个冒险提示词而丢失专属条件。旧回合保留旧绑定，后续采用哪个版本应以工作台实际选择及冻结记录为准。
